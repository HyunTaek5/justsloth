<ul>
<li>두 개의 SECLET 쿼리문의 결과를 처리하는데 사용하는 연산자이다.</li>
<li>UNION과 사용 조건이 유사하다.</li>
</ul>
<h4>사용 가능 조건</h4>
<ol>
<li>INTERSECT가 걸린 각각의 SELECT 쿼리는 같은 수의 열을 조회해야한다.</li>
<li>유사한 데이터 유형을 가지고 있어야한다.</li>
<li>각각의 SELECT 쿼리는 칼럼이 동일한 순서로 있어야한다.</li>
</ol>
<h3>차이점</h3>
<ul>
<li>UNION : 데이터가 1번 쿼리문 또는 2번 쿼리문의 조건에 부합되면, 해당 데이터가 출력된다. (OR 와 유사)</li>
