<h2>UNION / UNION ALL</h2>
<h3>문법</h3>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#1E1E1E;color:#D4D4D4" tabindex="0" data-language="sql" data-theme="dark-plus"><code data-language="sql" data-theme="dark-plus" style="display: grid;"><span data-line=""><span style="color:#D4D4D4">[SELECT sql문 1]</span></span>
<span data-line=""><span style="color:#569CD6">UNION</span></span>
<span data-line=""><span style="color:#D4D4D4">[SELECT sql문 2]</span></span></code></pre></figure>
<p>쿼리문 예시</p>
<ol>
<li>동일한 테이블에 다른 조건의 쿼리 2개를 합쳐서 paging 해야하는 경우</li>
</ol>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#1E1E1E;color:#D4D4D4" tabindex="0" data-language="sql" data-theme="dark-plus"><code data-language="sql" data-theme="dark-plus" style="display: grid;"><span data-line=""><span style="color:#569CD6">SELECT</span><span style="color:#D4D4D4"> id, </span><span style="color:#569CD6">name</span><span style="color:#D4D4D4">, </span><span style="color:#569CD6">description</span><span style="color:#569CD6"> FROM</span><span style="color:#D4D4D4"> book </span><span style="color:#569CD6">WHERE</span><span style="color:#D4D4D4"> book.name = </span><span style="color:#CE9178">'책이름'</span></span>
<span data-line=""><span style="color:#569CD6">UNION</span></span>
<span data-line=""><span style="color:#569CD6">SELECT</span><span style="color:#D4D4D4"> id, </span><span style="color:#569CD6">name</span><span style="color:#D4D4D4">, </span><span style="color:#569CD6">description</span><span style="color:#569CD6"> FROM</span><span style="color:#D4D4D4"> book </span><span style="color:#569CD6">WHERE</span><span style="color:#D4D4D4"> book.name = </span><span style="color:#CE9178">'책 이름'</span></span>
<span data-line=""><span style="color:#569CD6">LIMIT</span><span style="color:#B5CEA8"> 10</span><span style="color:#D4D4D4"> OFFSET </span><span style="color:#B5CEA8">0</span><span style="color:#D4D4D4">;</span></span></code></pre></figure>
<ol start="2">
<li>서로 다른 테이블의 비슷한 칼럼을 합치는 경우</li>
</ol>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#1E1E1E;color:#D4D4D4" tabindex="0" data-language="sql" data-theme="dark-plus"><code data-language="sql" data-theme="dark-plus" style="display: grid;"><span data-line=""><span style="color:#569CD6">SELECT</span><span style="color:#D4D4D4"> book_txn_date </span><span style="color:#569CD6">FROM</span><span style="color:#D4D4D4"> book_transaction</span></span>
<span data-line=""><span style="color:#569CD6">UNION</span></span>
<span data-line=""><span style="color:#569CD6">SELECT</span><span style="color:#D4D4D4"> recent_txn_date </span><span style="color:#569CD6">AS</span><span style="color:#D4D4D4"> book_txn_date </span><span style="color:#569CD6">FROM</span><span style="color:#D4D4D4"> book</span></span>
<span data-line=""><span style="color:#569CD6">LIMIT</span><span style="color:#B5CEA8"> 10</span><span style="color:#D4D4D4"> OFFSET </span><span style="color:#B5CEA8">0</span><span style="color:#D4D4D4">;</span></span></code></pre></figure>
<h3>특징</h3>
<ul>
<li>2개 이상의 SELECT 쿼리의 조회 결과를 결합 목적의 연산자이다.</li>
<li>결합하려는 쿼리문에서 리턴되는 데이터가 동일한 데이터 유형이어야 사용가능하다.</li>
<li>SELECT DISTINCT와 유사하게 UNION은 중복 데이터가 제외된다.</li>
</ul>
<h4>사용 가능 조건</h4>
<ol>
<li>UNION 이 걸린 각각의 SELECT 쿼리는 같은 수의 열을 조회해야한다.</li>
<li>유사한 데이터 유형을 가지고 있어야한다.</li>
<li>각각의 SELECT 쿼리는 칼럼이 동일한 순서로 있어야한다.</li>
</ol>
<h3>차이점</h3>
<ul>
<li>UNION : 데이터가 중복되는 경우 중복되는 데이터를 제외시킨다.</li>
<li>UNION ALL : 데이터가 중복되더라도 조건에 일치하면 모두 표시한다.</li>
