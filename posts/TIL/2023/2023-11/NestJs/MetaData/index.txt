<h2>Reflector &#x26; MetaData</h2>
<h3>개요</h3>
<p>Nest는 <code>Reflector</code> 라이브러리의 <code>createDecorator</code> 메소드와 기본 포함된 <code>@SetMetadata</code> 데코레이터를 활용해 생성한 데코레이터들이 Route Handler에 Custom 메타데이터를 적용할 수 있도록 허용한다.</p>
<h2>CreateDecorator</h2>
<p><code>createDecorator</code> 메소드를 사용해서 강타입 데코레이터를 생성하려면, 매개변수의 타입을 명시해야한다. 예를 들어 <code>Roles</code> 데코레이터를 생성할 때, <code>@Roles</code> 데코레이터의 매개변수가 어떤 타입을 받을 건지 (ex. <code>Role enum</code> 타입의 <code>array</code>를 받을건지, <code>string</code> 타입의 <code>array</code>를 받을건지 ) 제네릭을 통해 명시해줘야한다.</p>
<figure data-rehype-pretty-code-figure=""><pre style="background-color:#1E1E1E;color:#D4D4D4" tabindex="0" data-language="Typescripts" data-theme="dark-plus"><code data-language="Typescripts" data-theme="dark-plus" style="display: grid;"><span data-line=""> </span>
<span data-line=""><span>/**</span></span>
<span data-line=""><span>* 권한 체킹 Role 데코레이터</span></span>
<span data-line=""><span>* </span></span>
<span data-line=""><span>* @example @Roles(['ADMIN'])</span></span>
<span data-line=""><span>* @example @Roles([ Role.ADMIN ])</span></span>
<span data-line=""><span>**/</span></span>
<span data-line=""><span>export const Roles = Reflector.createDecoorator&#x3C;string[] | Role[]>();</span></span>
<span data-line=""> </span></code></pre></figure>
<p>해당 <code>Roles</code> 데코레이터를 API Controller 메소드 위에 추가하게되면, 추가된 메소드에 <code>Roles</code> 데코레이터의 메타데이터가 추가되고, <code>@Roles</code> 데코레이터 사용시 추가한 Role만 해당 메소드의 엔드포인트에 접근할 수 있게 된다. <code>Roles</code> 메타데이터가 추가된 메소드에 접근하려면 <code>Reflector</code>를 사용해야한다. <code>Reflector</code> 의<code>get</code> 메소드를 사용해서 Role의 메타데이터에 접근할 수 있다.</p>
