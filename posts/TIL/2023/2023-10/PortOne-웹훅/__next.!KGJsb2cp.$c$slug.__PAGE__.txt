<p>웹훅</p>
<h2>개념</h2>
<ul>
<li>특정 이벤트가 발생했을 때 타 서비스나 프로그램으로 알림을 보내는 기능</li>
<li>Webhook Provider는 해당 이벤트가 발행하면 HTTP POST 메소드 요청을 생성하여 Callback Url로 이벤트 정보를 전송한다.</li>
<li>주기적으로 데이터를 폴링하지않고, 원하는 이벤트에 대한 정보만 수신가능하여 리소스나 통신측면에서 웹훅이 더 효율적이다.</li>
</ul>
<h2>포트원에서 웹훅 연동이 필요한 이유</h2>
<ul>
<li>포트원 서버에서 클라이언트에 Response를 전달할 때, 해당 기기의 Wi-Fi 연결 끊김과 같은 통신 이슈나 브라우저 자동 리로드 등의 이슈로 클라이언트에서 결제 완료 Response를 받지 못하는 경우가 간헐적으로 발생한다.</li>
<li>위와 같이 가맹점 DB에서 결제 완료 처리가 안되는 경우를 보완하기 위해서 포트원 서버에서 가맹점 서버로 webhook 이벤트를 발송하여 결제 정보 Sync를 맞춘다.</li>
</ul>
<h2>웹훅 발송 타이밍</h2>
<p>결제 실패시에는 웹훅이 호출되지않는다.</p>
<ul>
<li>결제 승인시 - status: paid</li>
<li>가상계좌 발급시 - status: ready</li>
<li>가상계좌 입금 완료시 - status: paid</li>
<li>예약 결제 시도시 - status: paid | failed</li>
<li>관리자 콘솔에서 결제 취소시 - status: cancelled</li>
</ul>
